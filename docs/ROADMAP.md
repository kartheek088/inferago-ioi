# Roadmap

## Next (V1.x)
- Discourse/RSS presets for n8n and Make community forums (after terms review).
- Official open-data procurement APIs where permitted (e.g. international portals with public APIs).
- Organisation merge UI (manual merge exists for opportunities; orgs are conservative by design).
- Per-opportunity notes and owner tags.
- AI-assisted requirement extraction from long tenders (suggestions only; owner confirms;
  deterministic engine still decides).
- Pin resolved IPs in SafeHttp to close the DNS-rebinding window.
- Export shortlist / outreach pack as CSV or PDF.

## Later
- Authorised Discord bot connector (explicit server-owner permission only).
- Product Hunt API (subject to its commercial terms).
- Postgres option + background worker process if volume grows.
- Multi-user accounts with roles instead of a single shared token.
- Graph visualisation with force layout for large chains.

## Explicitly out of scope
- Automatic sending of email, calls, tender submission, vendor registration, signing.
- LinkedIn or freelance-marketplace scraping; CAPTCHA/paywall bypass.
